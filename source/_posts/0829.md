# 常识错题整理

```txt
张某在外偶遇李某跳江自尽，救人心切的张某将手机放在桥边后，从距江面十米高的桥上奋不顾身跳入江中，造成背部受伤，救人过程中张某用力过猛，致李某手臂拉伤，期间，路人王某因担心张某手机被踩踏曾将其拾起攥在手中，但围观群众过多，拥挤中还是不慎将手机摔坏。

对此，下列说法正确的是（    ）。

A 李某可就手臂拉伤向张某请求适当补偿
B 王某应对张某手机摔坏承担赔偿责任
C 李某应对张某背部受伤承担赔偿责任
D 张某可就手机摔坏向李某请求适当补偿

解析
A. 根据《民法典》第一百八十四条规定：“因自愿实施紧急救助行为造成受助人损害的，救助人不承担民事责任。”张某是为救跳江的李某实施紧急救助，过程中致李某手臂拉伤属于紧急救助的合理风险，张某无需承担责任，李某无权请求补偿。

B. 根据《民法典》第九百七十九条第一款规定：“管理人没有法定的或者约定的义务，为避免他人利益受损失而管理他人事务的，可以请求受益人偿还因管理事务而支出的必要费用；管理人因管理事务受到损失的，可以请求受益人给予适当补偿。”王某出于善意拾起手机，属于无因管理，且手机摔坏是因围观群众拥挤导致，王某对损害的发生没有故意或重大过失，无需对张某手机摔坏承担赔偿责任。

C. 根据《民法典》第一百八十三条规定：“因保护他人民事权益使自己受到损害的，由侵权人承担民事责任，受益人可以给予适当补偿。没有侵权人、侵权人逃逸或者无力承担民事责任，受害人请求补偿的，受益人应当给予适当补偿。”张某背部受伤是因救人所致，李某作为受益人应对其“补偿”而非“赔偿”。

D. 张某的手机是因救助李某而放置在桥边，最终被摔坏，属于因保护他人民事权益而遭受的财产损失。本案中手机摔坏无明确侵权人，李某作为受益人，张某有权请求其给予适当补偿。
```


```txt
李某拾得一标有“机密”字样的移动硬盘，破解后发现其中存在大量军用无人机照片。遂将照片卖给某国外网站，情节特别严重。经鉴定，上述照片属于国家秘密。李某的行为应认定为（    ）。

A 间谍罪    B 故意泄露国家秘密罪    C 为境外非法提供国家秘密罪      D 非法获取国家秘密罪

解析
A. 间谍罪，是指参加间谍组织，接受间谍组织及其代理人的任务，或者为敌人指示轰击目标，危害国家安全的行为。本题李某的行为不构成间谍罪。

B. 故意泄露国家秘密罪，是指国家机关工作人员或其他有关人员，违反保守国家秘密法的规定，故意泄露国家秘密，情节严重的行为。

C. 行为人将国家秘密泄露给境外的机构、组织、人员的，应认定为为境外非法提供国家秘密罪。本题中，李某将标有“机密”的移动硬盘中大量军用无人机照片，卖给某“国外网站”，且情节特别严重，构成为境外非法提供国家秘密罪。

D. 非法获取国家秘密罪，是指以窃取、刺探、收买方法，非法获取国家秘密的行为。本题李某的行为不构成非法获取国家秘密罪。
```

```txt
某企业因原材料价格上涨需要调整生产规模，因而向其他设备商租赁了新设备。经济学中此类成本是（    ）。

A 生产设备的折旧费，属于隐性成本
B 已发生的无法收回的成本，属于沉没成本
C 增加单位产量而发生的成本，属于边际成本
D 实际货币支出，属于显性成本

解析
A. 隐性成本是指厂商本身拥有且被用于生产过程的那些生产要素的总价格，不发生实际货币支付，比如自有资金的利息、自有厂房的租金、企业家才能的报酬等。企业是租赁设备，并非自有设备，不存在设备折旧费，不属于隐性成本。

B. 沉没成本是指已经发生、无法收回的成本，不管后续做什么决策都改变不了，比如已经花掉的广告费、已经购买无法退货的设备款。题干是为调整生产规模新增租赁设备，是新增支出，并非已经花出去、收不回的钱，不属于沉没成本。

C. 边际成本是指每增加一单位产量所带来的总成本增加额，关注的是“产量变化→成本变化”。题干强调的是租赁设备这一行为的成本性质，而非总成本变动额，不属于边际成本。

D. 显性成本是指企业在生产要素市场上购买或租用所需生产要素的实际货币支出，如支付租金、工资、原材料费用等。题干企业向设备商租赁新设备并支付租金，是实实在在的货币支出，属于显性成本。
```

```txt
去餐馆吃饭时，在指定平台签到、打卡、发好评，就可以获赠一份小菜或甜品；网购或点外卖时，包装里常夹着“好评返现”卡片，按照指引给好评就能拿到几元红包；在指定平台发布探店好评，就能置换一顿“霸王餐”······从餐饮、网购到住宿、休闲，“好评返现”已悄然走入大众生活的方方面面。商家“好评返现”（    ）。

A 属于正当竞争，保障消费者批评监督权
B 旨在让利促销，是正当的产品推广手段
C 涉嫌虚假宣传，侵害其他消费者知情权
D 属于混淆行为，损害了他人的商业信誉

解析
1. 根据《反不正当竞争法》第九条规定：“经营者不得对其商品的性能、功能、质量、销售状况、用户评价、曾获荣誉等作虚假或者引人误解的商业宣传，欺骗、误导消费者和其他经营者。经营者不得通过组织虚假交易、虚假评价等方式，帮助其他经营者进行虚假或者引人误解的商业宣传。”由此可知，商家“好评返现”的行为，是通过虚假用户评价，侵害其他消费者的知情权，并非正当竞争行为，涉嫌虚假宣传。

2. 根据《反不正当竞争法》第七条第一款规定：“经营者不得实施下列混淆行为，引人误认为是他人商品或者与他人存在特定联系：
（一）擅自使用与他人有一定影响的商品名称、包装、装潢等相同或者近似的标识；
（二）擅自使用他人有一定影响的名称（包括简称、字号等）、姓名（包括笔名、艺名、网名、译名等）；
（三）擅自使用他人有一定影响的域名主体部分、网站名称、网页、新媒体账号名称、应用程序名称或者图标等；（四）其他足以引人误认为是他人商品或者与他人存在特定联系的混淆行为。”
由此可知，商家“好评返现”并非混淆行为。
```

```txt
某茶业公司销售过期茶叶，市场监管部门对该公司处以罚款2万元，该公司不服，向法院起诉。一审法院认为该行政行为合法，判决驳回该公司的诉讼请求。二审法院判决将罚款变更为5000元。下列说法正确的是（    ）。

A 该公司销售过期茶叶的行为属于法律事件
B 法院和该公司之间的法律关系属于绝对法律关系
C 市场监管部门对该公司处以罚款的行为属行政处分
D 二审法院的改判体现上级人民法院对下级人民法院审判工作的监督

解析
A. 以是否以人们的意志为转移作标准，可以将法律事实分为法律事件和法律行为。法律事件是法律规范规定的、不以当事人的意志为转移而引起法律关系形成、变更或消灭的客观事实，如自然灾害，人的出生死亡等。法律行为是以当事人的意志转移而引起法律关系形成、变更和消灭的客观事实。该公司销售过期茶叶的行为属于法律行为，而非法律事件。

B. 绝对法律关系是指权利主体特定而义务主体不特定的法律关系；相对法律关系是指权利主体和义务主体都特定的法律关系。本题中，在法院和该公司之间的诉讼法律关系中，权利主体和义务主体都特定，因此，这属于相对法律关系，而非绝对法律关系。

C. 行政处分是调整国家行政职务关系的行政纪律措施。根据《公务员法》第六十二条规定：“处分分为：警告、记过、记大过、降级、撤职、开除。”行政处罚是指国家行政机关对构成行政违法行为的公民、法人或者其他组织实施的行政法上的制裁。根据《行政处罚法》第九条规定：“行政处罚的种类：······（二）罚款、没收违法所得、没收非法财物；······”本题中，市场监管部门对该公司处以罚款的行为属于行政处罚，而非行政处分。

D. 根据《宪法》第一百三十二条第二款规定：“最高人民法院监督地方各级人民法院和专门人民法院的审判工作，上级人民法院监督下级人民法院的审判工作。”这表明上下级人民法院之间是监督关系。这种监督主要体现在上级人民法院按照上诉程序、审判监督程序及死刑复核程序对下级人民法院具体案件的监督，纠正错误的判决和裁定。因此，二审法院的改判体现了上级人民法院对下级人民法院审判工作的监督。
```

# 常识积累

## 乐器
```txt
1. 扬琴是击奏弦鸣乐器，不是拉弦乐器。起源于亚述和波斯，11世纪传入欧洲，明末清初从波斯、阿拉伯传入中国。
2. 长号俗称“拉管”，属于唇簧气鸣乐器，是西洋乐器中的铜管乐器，不是中国传统乐器。
3. 笙是中国古老的吹奏乐器，商周时即已流行。
4. 钢琴是击奏弦鸣乐器，起源于欧洲，是典型的西洋乐器，不是中国传统乐器。
```

## 关于梅花的作品
```txt
1. 《白梅》是元代王冕的诗作。诗句是：“冰雪林中著此身，不同桃李混芳尘。忽然一夜清香发，散作乾坤万里春。”诗人采取托物言志的手法歌咏了白梅的高洁品格，同时借梅自喻，表达自己的人生态度。
2. 《梅谱》是元代王冕的作品，王冕一生爱好梅花，种梅、咏梅，又攻画梅。所画梅花花密枝繁，生意盎然，劲健有力，对后世产生了较大影响。《梅谱》为早期画梅理论著述。
3. 《病梅馆记》是清代文学家龚自珍创作的一篇散文，全篇以梅喻人，揭露了封建传统思想和病态的社会对人的束缚与摧残，表达了作者要求挣脱枷锁、自由发展的愿望及其迫切的救世之心。
4. 《山园小梅》是宋代林逋的作品。林逋（和靖），隐居杭州孤山，不娶无子，而植梅放鹤，称“梅妻鹤子”，被传为千古佳话。他的《山园小梅》诗中名句：“疏影横斜水清浅，暗香浮动月黄昏。”是梅花的传神写照，脍炙人口，被誉为千古绝唱。
```

## 成语发生的地点
```txt
1. “乐不思蜀”出自《三国志·蜀书·后主传》，讲的是三国时期刘禅投降魏国迁至魏都洛阳后，一味享乐，不想着回到故国的故事。“蜀”指蜀国，今四川地区
2. “合浦珠还”出自南朝宋·范晔《后汉书·孟尝传》，该成语描述合浦郡因滥采导致珍珠流失，后因合浦太守孟尝的合理改革使得珍珠捕捞得以恢复。合浦是古代著名产珠地，位于今广西北海市合浦县
3. “黔驴技穷”出自柳宗元的寓言《黔之驴》，比喻有限的一点本领也已经用完了。“黔”指的是今贵州地区
4. “邯郸学步”出自《庄子》，描述燕国少年到赵国都城邯郸模仿当地人步态，不但没学会还忘记了自己原来的步态。“邯郸”即今河北省邯郸市
```

## 中国古代文学流派
```txt
1. 公安派兴起于明代复古思潮盛行的背景下，以湖北公安籍袁宗道、袁宏道、袁中道三兄弟为核心，因籍贯得名。公安派主张文学应随时代演变而创新，并提出“独抒性灵，不拘格套”的理论纲领，强调直抒真情实感，反对形式束缚。而“文必秦汉，诗必盛唐”是明代前七子提出的核心文学理论，主张文章应以秦汉时期的古文为典范，诗歌需遵循盛唐时期的格调气象。

2. 桐城派是中国清代文坛上最大的散文流派，崛起于清初，亦称“桐城古文派”，以其代表人物戴名世、方苞、刘大櫆、姚鼐的籍贯均为江南安庆府桐城得名，其四人被称为桐城派“四祖”。桐城派主张学习左传、史记，讲究义法，提倡义理，要求语言雅洁，反对俚俗。

3. 江西诗派以北宋黄庭坚为代表，主张“点铁成金”“夺胎换骨”，风格瘦硬生新，代表人物包括黄庭坚、陈师道、陈与义等。陆游虽受江西诗派影响，但突破其极限，形成自己独特的爱国主义与豪放派风格，《书愤》《示儿》是其晚年抒发爱国情怀的代表作，风格沉郁悲壮，不属于江西诗派的经典诗作。

4. 边塞诗派是唐代的诗歌流派，以描写边塞风光、军旅生活、爱国情怀为核心，风格雄浑壮阔、慷慨激昂，代表人物是高适、岑参、王昌龄、王之涣等。而王维、孟浩然是唐代山水田园诗派的代表人物，其诗作以描写山水风光、田园生活为核心，风格清新自然、意境悠远。
```

## 三角洲
```txt
1. 黄河三角洲，是指黄河入海口携带泥沙在渤海凹陷处沉积形成的冲积平原，其油气、卤水、土地资源丰富，中国的胜利油田即在黄河三角洲区域内。
2. 尼罗河三角洲位于埃及北部，临地中海。由尼罗河携带的泥沙在入海口冲积而成，面积2.4万平方公里。
3. 密西西比河三角洲是密西西比河携带的泥沙在美国路易斯安那州南部的墨西哥湾向海注入形成的泥沙堆积三角洲。密西西比河三角洲属亚热带湿润气候，气候温和，雨量充沛。
4. 湄公河三角洲位于越南的最南端、柬埔寨东南端，是越南最富饶的地方和越南人口最密集的地方，也是东南亚地区最大的平原。
```

## 文学常识
```txt
1. 词最初称“曲子词”，起源于隋唐时期，盛唐至晚唐逐渐成熟。与音乐紧密结合，称为“合乐可歌”。句式突破古诗的整齐对仗，呈现长短不齐的特点，故称“长短句”。晚唐温庭筠、五代李煜等进一步推动词的发展，宋代达到顶峰。
2. “字字写来都是血，十年辛苦不寻常”这句话是对曹雪芹创作《红楼梦》的精准概括。曹雪芹以“批阅十载，增删五次”的心血打磨作品，书中不仅寄托个人际遇，更折射社会百态。“十年辛苦”对应其创作周期，“字字是血”体现作品的厚重与情感浓度。
3. 杜甫曾担任唐朝工部员外郎，后人尊称其“杜工部”，《杜工部集》文集以官爵命名，表述正确；“文正”是北宋范仲淹的谥号，而非字号，范仲淹的字是希文，无知名号。
4. 赋起源于战国，成熟于汉代，文体特点是介于诗与散文之间。既有诗的韵律感，讲究声调和谐、押韵，又有散文的铺陈叙事性，铺采摛文，体物写志，可自由状物抒情。
```

## 起火时的做法
```txt
1. 遇到油锅起火，应先关闭煤气阀门，用灭火器灭火。如身边没有灭火器，可用锅盖迅速盖住油锅，燃烧的油火接触不到空气，便会因缺氧而熄灭，也可以往油锅里放新鲜蔬菜，利用蔬菜与着火油的温度差，使锅里燃烧着的油温度迅速下降，当油达不到燃点时，火就自动熄灭了。因此，蔬菜也是天然的“灭火剂”，将切好的蔬菜迅速倒入锅内同样也能起到灭火作用。

2. 煤气罐着火阀门没有损坏的情况下，首先用湿毛巾包住手然后直接关闭即可；如果煤气罐着火阀门损坏关不上的情况下，把煤气罐周围的可燃物移走，同时开窗通风，让空气流动，如果火已经扑灭但还有液化气往外泄漏的情况要第一时间断电，疏散建筑内的人员，拨打119报警；如果煤气罐着火阀门损坏且倾倒在地上的情况下，可以用湿毛巾包住手把煤气罐扶正，防止罐体受热过度。

3. 发电机起火时，一般不推荐直接使用水灭火，因为水可能导致电气短路，扩大火势。应首先切断电源，再选择合适的灭火器材进行扑救，如干粉灭火器或二氧化碳灭火器等。

4. 发动机起火通常涉及油类或电气火。二氧化碳灭火器，适宜扑灭可燃液体和可燃气体的初起火灾，以及带电设备和精密电子仪器、贵重设备的火灾。因此，发动机起火，可使用二氧化碳灭火器灭火。
```
